## ✨ 六大互動教學＆《勁旅對決》實戰關卡

### 0. 🔥《勁旅對決》實戰比賽模式（高互動投打對決＋守備傳球＆跑壘戰術 QTE）
參考《MLB 勁旅對決 (MLB Rivals)》打造的高張力電視轉播級互動比賽模式：
- **雙鏡頭無縫切換**：
  - **3D 本壘投打對決視角**：整合右上角即時壘包雷達小地圖 (PIP Radar)、左側揮棒時機條 (Timing Bar)、好球帶動態落點預測圈與擊球爆擊慢動作特效。
  - **3D 全景球場物理追蹤視角**：擊球瞬間自動切換至全景球場，即時呈現 **🟡 空中飛行拋物線**、**🟢 內野紅土 (`e=0.50`)／外野草地 (`e=0.36`) 連續彈跳與塵土粒子特效**，以及 **🔵 草皮摩擦減速滾動軌跡線**。
- **⚾ 王牌投手微操模式（Pitcher Mode）**：
  - **5 張專屬球種卡**：🔥 四縫線直球、⚡ 二縫線伸卡、🗡️ 犀利滑球、🐢 圈指變速球、🌈 大曲球，點選即顯示變化弧線預覽箭頭。
  - **《勁旅對決》動態縮圈精準放球計量環 (Pinpoint Release Ring)**：啟動投球後外圈快速縮小，在與黃色甜蜜圈重合瞬間點擊放球即可觸發 `PERFECT 完美放球`，球威與變化幅度 +25%！
  - **即時守備飛撲 QTE 與自由傳球雙殺**：球打入內外野時可抓準時機點擊 `🦸‍♂️ 飛撲美技攔截 (Dive QTE)`，接球後自由點擊 `傳一壘 1B`、`傳二壘 2B`、`傳三壘 3B` 或 `傳本壘 HOME` 策動雙殺或阻殺本壘！
- **🏏 強棒打者微操模式（Batter Mode）**：
  - **巧打 (Contact) vs 強振 (Power) 雙模式切換**：巧打擴大甜蜜點游標容錯率；強振集中甜蜜點並大幅提升擊球初速與全壘打機率。
  - **壘上跑壘戰術即時指揮**：球在場內滾動或高飛時，可即時下達 `⚡ 全員加速衝下一壘！`、`🛑 踩住壘包等待 (Tag Up)`，並在野手傳球逼近壘包時按下 `🦶 曲腿滑壘 QTE (Figure-4 Slide)` 閃避觸殺！
- **🔥 勁旅鬥志必殺能量槽 ＆ 三大對手球隊**：
  - 累積三振、完美放球、安打或滑壘可集滿 `100% 鬥志能量`，一鍵發動「🔥 勁旅必殺技」突破球速與擊球初速極限！可自由挑戰 **🐯 猛虎少棒隊**、**🦅 蒼鷹菁英隊** 與 **🐉 霸龍全明星**，並內建 Web Audio 合成擊球清脆聲、手套接球聲與全壘打歡呼音效。

### 1. ⚾ 投球物理實驗室與握法圖解
- **真實空氣動力馬格努斯效應 (Magnus Effect)**：
  - 可自由調整 **出手球速 (60~105 km/h)** 與 **手指扣球轉速 (600~2400 RPM)**。
  - 畫面同時對比 **灰色虛線（無旋轉純重力拋物線）** 與 **亮色實線（真實旋轉馬格努斯軌跡線）**，清楚看見四縫線直球如何「抵抗地心引力上浮」、二縫線如何「側向伸卡下沉」、曲球如何「前旋大幅下墜」，以及「挖地瓜球」提前撞擊紅土彈跳減速的物理過程！
- **不同球種握法圖解**：
  - 🔥 **四縫線直球 (4-Seam Fastball)**：食指與中指橫跨馬蹄形縫線，球路最直最穩，傳接球與投球必學基本功！
  - ⚡ **二縫線直球 (2-Seam Fastball)**：手指順著窄縫線擺放，進壘前微幅下沉。
  - 🐢 **掌心變速球 (Changeup)**：適合少棒的安全變化球，用直球揮臂速度投出慢速下墜球。
  - 🌈 **曲球 (Curveball 旋轉原理認識)**：認識前旋下墜原理，並特別提醒小四學童**保護手肘、不刻意扭轉手腕**。
- **身體的投球方法（五步驟分解動畫）**：
  - `1. 站穩抬腿` ➔ `2. 跨步展翅成 L 型` ➔ `3. 轉腰帶動手肘` ➔ `4. 高點放球扣腕` ➔ `5. 收尾與防守姿勢`。

### 2. 🧤 守備、傳接球與守壘包技巧
- **滾地球「正三角形站姿 ＋ 鱷魚嘴巴雙手接球」**：雙腳與手套形成正三角形，手套在下、空手在上像鱷魚張嘴，接球不漏接、拿球傳球更快速。
- **高低球接法與墊步傳球 (Crow Hop)**：胸口以上大拇指相連、腰部以下小拇指相連；接球後利用後腳墊步側身對準目標傳球。
- **守壘包的技巧（封殺 vs 觸殺動態模擬）**：
  - **一壘封殺 (Force Out)**：腳踩壘包「朝向場內的內側邊緣」並向傳球方向跨步延伸，避免踩在壘包中央與跑者相撞。
  - **二／三壘觸殺 (Tag Play)**：雙腳跨站壘包兩側不擋跑道，將手套放在壘包前地面等跑者滑進來觸殺。

### 3. 🏏 打擊握棒、揮棒與擊球軌道（含滾動摩擦物理）
- **敲門關節對齊握棒法**：雙手握棒時將「敲門關節（第二指關節）」排成一直線，手腕轉動最靈活。
- **擊球點 ＆ 飛球彈跳滾動模擬器**：內建擊球點放大鏡，自由調整擊球仰角與初速，觀察滾地球、平飛安打、深遠長打與內野沖天炮的 **3D 飛行、連續彈跳與草皮減速滾動軌跡**。
- **擊球後跑一壘路線**：比較「內野滾地球直線全力衝過一壘往右轉」與「外野安打香蕉彎踩內側角衝二壘」。

### 4. 🏃‍♂️ 壘上跑壘情境戰術模擬器
- **一壘有人＋滾地球**：強迫進壘 (Force Play)，看到滾地球立刻低頭全力衝二壘。
- **三壘有人＋外野高飛球**：少於兩出局時先回三壘踩壘等待 (Tag Up)，野手接球瞬間全力衝本壘得分。
- **兩出局 (2 Outs) 黃金法則**：球一打出去的瞬間，壘上所有跑者立刻全力起跑！
- **離壘與第二離壘**：面向本壘採用「側滑步（不交叉腳）」，隨時準備進壘或回壘。
